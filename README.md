# PixelPulse

The official website and resource hub for **PixelPulse** — showcasing custom Minecraft Bedrock Edition content, server updates, project changelogs, and community news.

---

## 🌟 Overview

PixelPulse is a dedicated Minecraft Bedrock development group specializing in custom maps, server infrastructure, and game addons. This repository hosts the front-facing web portal for players and creators to explore updates and downloads.

---

## ✨ Features

* **Addons & Content Catalog:** Browse and download custom Bedrock maps, resource packs, and tools.
* **Live Patch Notes & Changelogs:** Real-time server and project updates rendered with native Discord markdown formatting.
* **Community Announcements:** Stay up-to-date with recent developments and project news.
* **Responsive Dark Theme:** Fast, lightweight, mobile-friendly interface designed for desktop and mobile players.

---

## 🛠️ Built With

* **Frontend:** HTML5, CSS3, JavaScript (ES6)
* **Backend Services:** Firebase Database & Auth
* **Hosting:** GitHub Pages
